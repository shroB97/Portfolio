# Shrobanti Banerjee — Public Portfolio

A responsive, aesthetic yellow portfolio website containing:

- About section
- LinkedIn and GitHub links
- Resume page
- Experience and skills
- Featured GitHub projects
- Contact section
- Mobile-responsive design

## Run locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Important customization

Replace `your-email@example.com` in both `index.html` and `resume.html`.

## Publish for everyone

### GitHub Pages

1. Create a new public GitHub repository, for example `shrobanti-portfolio`.
2. Upload all files from this folder.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/root`, then save.
6. GitHub will provide a public link.

You can also deploy the same folder through Netlify or Vercel.
